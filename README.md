# DevAssistant MCP Server

DevAssistant MCP Server — это локальный сервер на базе протокола Model Context Protocol (MCP), написанный на Python с использованием фреймворка FastMCP.

Проект расширяет возможности AI-ассистентов (Claude Desktop, MCP Inspector и др.), предоставляя им прямое управление локальной базой данных задач разработки и возможность выполнять сетевые проверки (health-check) веб-сервисов.

## Архитектура и возможности

Сервер работает поверх транспорта Stdio (стандартный поток ввода-вывода), что обеспечивает высокую скорость взаимодействия с AI-клиентами и безопасность.

### Основные функции:
1. Управление локальным бэклогом (SQLite):
   - Создание задач и багов с указанием приоритета (low, normal, high).
   - Чтение и отображение текущих задач из базы данных.
   - Автоматическая инициализация структуры таблицы при первом запуске.
2. Мониторинг веб-ресурсов:
   - Проверка HTTP-статуса ответа нужного URL.
   - Измерение времени отклика сервера (latency) в секундах.
   - Обработка ошибок соединения (таймауты, недействительные URL).

## Технологический стек

- Язык программирования: Python 3.10+
- MCP Фреймворк: FastMCP 4.x
- База данных: SQLite3 (локальный файл dev_tasks.db)
- Сетевые запросы: requests
- Протокол связи: Stdio Transport Protocol

## Полное описание инструментов

### 1. add_dev_task
- Описание: Добавляет новую задачу или баг в локальную базу данных (SQLite) разработчика.
- Принимаемые аргументы:
  - title (string, обязательный): Описание, заголовок или суть создаваемой задачи.
  - priority (string, опционально): Уровень приоритета задачи (low, normal, high). По умолчанию: normal.
- Возвращаемое значение: Текстовое подтверждение об успешном создании задачи с указанием её ID.
- Пример ответа: Успешно создана задача #1: "Исправить баг авторизации" с приоритетом high.

### 2. list_dev_tasks
- Описание: Извлекает и возвращает полный список всех сохранённых задач из бэклога.
- Принимаемые аргументы: Отсутствуют.
- Возвращаемое значение: Отформатированный список всех записей (ID, название, статус, приоритет).
- Пример ответа:
  ID: 1 | Исправить баг авторизации | Статус: todo | Приоритет: high
  ID: 2 | Написать тесты для API | Статус: todo | Приоритет: normal

### 3. check_url_health
- Описание: Выполняет HTTP GET-запрос к указанному URL для проверки доступности и скорости ответа.
- Принимаемые аргументы:
  - url (string, обязательный): Полный URL-адрес ресурса (например, https://api.github.com).
- Возвращаемое значение: Отчёт о состоянии ресурса, HTTP-код и время задержки в секундах.
- Пример ответа: URL https://api.github.com доступен! Статус: 200, Время отклика: 0.18 сек.

## Установка и запуск

1. Клонирование репозитория:
   git clone https://github.com/ВАШ_НИКНЕЙМ/mcp-dev-assistant.git
   cd mcp-dev-assistant

2. Создание и активация виртуального окружения:
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # macOS/Linux: source .venv/bin/activate

3. Установка зависимостей:
   pip install -r requirements.txt

4. Запуск сервера:
   python server.py

## Обработка ошибок и логирование

- Ошибки сети: При недоступности проверяемого URL инструмент check_url_health возвращает сообщение об ошибке вместо падения сервера.
- База данных: Подключение к SQLite открывается и закрывается изолированно в рамках каждого вызова функции.
